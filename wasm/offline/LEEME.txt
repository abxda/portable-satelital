TALLER OFFLINE (HABILITADOR) - ML para detectar zonas urbanas
Curso de Analisis de Imagenes Satelitales - Dr. Abel Coronado
===============================================================

PARA EL ALUMNO:
  Windows:  doble clic en  TallerServidor.exe
            Si Windows muestra el aviso azul de SmartScreen:
            "Mas informacion" -> "Ejecutar de todas formas"
            (abajo explicamos por que aparece y como verificar el programa)
  Linux:    ./taller-servidor-linux-amd64      (antes: chmod +x)
  macOS:    ./taller-servidor-macos-arm64      (antes: chmod +x; si Gatekeeper
            bloquea: xattr -d com.apple.quarantine taller-servidor-macos-arm64)

  Se abre tu navegador con el taller. No necesitas internet.

TUS PROPIOS DATOS (esto es lo importante):
  Copia tus imagenes GeoTIFF y tus etiquetas a la carpeta  mis_datos\
  con el Explorador. El cuaderno las encuentra al instante (seccion
  "El taller es tuyo"). Ya hay un ejemplo dentro para que pruebes.

PARA EL AREA DE TI / CIBERSEGURIDAD:
  TallerServidor es un servidor de archivos estaticos de ~100 lineas de
  Go (codigo completo: github.com/abxda/portable-satelital, carpeta
  taller-servidor/). No esta firmado con Authenticode (proyecto educativo
  sin certificado comercial) pero su procedencia es VERIFICABLE
  criptograficamente, algo mas fuerte que la reputacion de SmartScreen:

  1. Compilado en GitHub Actions con artifact attestation:
       gh attestation verify TallerServidor.exe --repo abxda/portable-satelital
     prueba matematica de que el binario salio de ese codigo publico.
  2. Build reproducible: compilelo usted mismo (go build -trimpath) y
     obtendra el MISMO SHA-256.
  3. SHA-256 publicado en el release de GitHub + analisis VirusTotal.

  Comportamiento: escucha SOLO en 127.0.0.1, sirve solo-lectura las
  carpetas sitio\ y mis_datos\, no acepta subidas, no requiere
  administrador, no toca registro ni firewall. Borrar la carpeta = fin.

  El contenido de sitio\ es JupyterLite + Pyodide: Python cientifico en
  WebAssembly, dentro de la caja de arena del navegador.

  Cadena de verificacion completa:
  https://github.com/abxda/portable-satelital/blob/main/VERIFICACION.md
