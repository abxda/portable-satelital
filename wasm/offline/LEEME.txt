TALLER OFFLINE - Machine Learning para detectar zonas urbanas
Curso de Analisis de Imagenes Satelitales - Dr. Abel Coronado
===============================================================

PARA EL ALUMNO:
  Windows:     doble clic en  Iniciar_Taller.bat
  Linux/macOS: ejecutar  ./iniciar_taller.sh
  Se abre tu navegador con el taller. No necesitas internet.
  Para terminar: cierra la ventanita del servidor (o Ctrl+C).

PARA EL AREA DE TI / CIBERSEGURIDAD (este kit NO trae ejecutables):
  La carpeta contiene SOLO datos estaticos (sitio\) y lanzadores de texto
  auditable (.bat / .sh). El servidor lo pone el sistema, por canal oficial:

  * WINDOWS -> IIS Express, el servidor ligero gratuito de Microsoft.
    Instalacion unica por TI con el MSI oficial firmado por Microsoft:
    https://www.microsoft.com/en-us/download/details.aspx?id=48264
    El .bat solo lo invoca:  iisexpress.exe /path:sitio /port:8765
    Binario firmado "Microsoft Corporation", corre como usuario normal,
    escucha SOLO en localhost, sirve solo lectura. El unico archivo de
    configuracion es sitio\web.config (tipos MIME; 20 lineas auditables).

  * LINUX -> caddy o nginx desde el REPOSITORIO de la distro (paquetes
    firmados GPG por la distro), o python3 que ya es parte del sistema.
    El .sh usa: caddy file-server  (o python3 -m http.server).

  * macOS -> caddy via Homebrew, o el Python oficial de python.org
    (firmado y notarizado por la Python Software Foundation).

  En todos los casos: loopback unicamente (127.0.0.1), sin administrador
  para EJECUTAR, sin reglas de firewall, sin tocar el registro. Borrar la
  carpeta elimina todo.

  El contenido de sitio\ es JupyterLite + Pyodide: Python cientifico
  compilado a WebAssembly que corre DENTRO del navegador, en su caja de
  arena estandar. Nada se instala en el equipo.

  Cadena de verificacion completa del proyecto:
  https://github.com/abxda/portable-satelital/blob/main/VERIFICACION.md
